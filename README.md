## Project Overview

This MBA Business Analytics project focuses on understanding customer segmentation and customer purchasing patterns in an eCommerce environment using data modelling and analytics.

The project analyses customer characteristics across demographic, geographical, psychographic, and behavioural dimensions to understand different customer groups and their purchasing behaviour.

## Objectives

- To analyse customer characteristics using different segmentation dimensions.
- To understand customer purchasing patterns in an eCommerce environment.
- To apply data modelling techniques for customer analysis.
- To identify useful business insights from customer data.
- To support data-driven decision-making.

## Tools & Technologies

- Power BI
- Microsoft Excel
- SQL
- Data Modelling
- Data Analysis
- Data Visualization

## Project Methodology

The study uses customer survey data and analyses the responses across four major dimensions:

- Demographical
- Geographical
- Psychographical
- Behavioural

The collected data is processed and analysed to identify patterns and generate meaningful business insights.

## Dashboard

The Power BI dashboard presents:

- Customer segmentation analysis
- Customer purchasing pattern analysis
- Demographic distributions
- Gender analysis
- Customer behaviour insights
- Interactive filters and slicers
- Data visualizations
